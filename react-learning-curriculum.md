# React.js Learning Curriculum: From Beginner to Senior Developer

## Overview
This curriculum is designed to take you from complete beginner to senior React developer level. Each stage builds upon the previous one, with practical tests to validate your understanding.

## Prerequisites
- Basic HTML, CSS, and JavaScript knowledge
- Understanding of ES6+ features (arrow functions, destructuring, modules, etc.)
- Familiarity with npm/yarn package managers

---

## Stage 1: React Fundamentals (Week 1-2)

### Learning Objectives
- Understand React's core concepts and philosophy
- Learn JSX syntax and rules
- Master component creation and composition
- Understand props and state management
- Learn event handling in React

### Topics Covered
1. **React Introduction**
   - What is React and why use it?
   - Virtual DOM concept
   - React ecosystem overview

2. **JSX Fundamentals**
   - JSX syntax and rules
   - Embedding expressions
   - Conditional rendering
   - Lists and keys

3. **Components**
   - Functional components
   - Component composition
   - Props and prop drilling
   - Component lifecycle (basic)

4. **State Management**
   - useState hook
   - State updates and immutability
   - State lifting

5. **Event Handling**
   - Event handlers in React
   - Synthetic events
   - Form handling

### Practical Projects
- Todo List App (basic CRUD operations)
- Counter App with multiple counters
- Simple Form with validation

### Stage 1 Test: "React Fundamentals Assessment"
**Duration:** 2 hours
**Format:** Practical coding test

**Test Requirements:**
1. Create a React app with multiple components
2. Implement state management using useState
3. Handle user interactions and form submissions
4. Demonstrate proper JSX usage
5. Show component composition and prop passing

**Passing Criteria:** Complete all requirements with clean, readable code
